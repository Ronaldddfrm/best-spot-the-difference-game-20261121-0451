Spot the Difference — three original hand-drawn scenes (Sunny Garden, Harbour at Dusk, Moon Observatory) with 25 hidden changes, hints, a countdown timer and streak scoring. Two near-identical pictures side by side: click a difference on either panel to mark it with a green ring and checkmark, watch the counter tick down, and clear the scene before time runs out.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the game is plain static files under `game/` and plays with no network request. Keyboard: `H` hint, `R` new round, `1`/`2`/`3` switch scenes.
